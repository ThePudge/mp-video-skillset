وضعیت سیستم

    
    
    
    
    
      
    چطور کار می‌کند
    
      
      
        
    1. در برند و استایل یک بار پیج، رنگ‌ها، فونت‌ها و سبک کارت‌ها را تنظیم کن.
      2. 
        
    2. در پروژه ویدیو، ویس یا رفرنس‌ها را بکش و رها کن و هدف ویدیو را بنویس.
      3. 
        
    3. حالت ادیت را انتخاب کن: حرفه‌ای (Claude) یا سبک (هوش مصنوعی ساده‌تر/رایگان)، بعد دکمه‌ی ذخیره را بزن و جمله‌ای که نشان می‌دهد را برای هوش مصنوعی بفرست. (تب راهنما)
      4. 
        
    4. اول استوری‌بورد می‌آید (چند ثانیه، بدون رندر): در بازبینی متن برنامه و تصویر و صدای هر صحنه را ببین، یادداشت بگذار یا تأیید کن. رندر سنگین فقط بعد از تأیید.
      5. 
        
    5. بعد از تأیید، ویدیوی نهایی در خروجی‌ها آماده می‌شود.
      6. 
      
    
    
    
  
    

  
  
    
    
    
      
    چه کسی ادیت کند؟
    
      
    
        
        
      
    
      
    هر دو حالت اول استوری‌بورد را در بازبینی نشان می‌دهند (چند ثانیه، بدون رندر) و فقط بعد از تأیید تو رندر می‌کنند.
    
    
    
    
    
      
    
        
    فایل‌ها
    
        
    
          
          
          
          
          
        
    
        
    
        
      
        
      
        
      ترتیب و نقش کلیپ‌ها
      
        
      بکش و رها کن تا ترتیب عوض شود. اصلی = صحبت، به همین ترتیب · تکرار = یک بار دیگر همان کلیپ بالایی (بهترینش می‌ماند) · بی‌رول = تصویر کمکی (اسکرین‌ریکورد، محصول…) که روی صحبت پخش می‌شود.
      
        
        
      
        
      
        
        
        هدف ویدیو
        
        
        
        
        
        
        
      
        
    
        
  
        

  
  
        
    
        
      این تنظیمات برای:
      
        
      
      
    
        
    
        
      
        
        
        برند شما
        
        
        عکس
        لوگو
        
        
        
        
        
        
        
          
          
          
          
        
        
      
        
      
        
        
        استایل ویدیو
        
        
        تم
        
        
        
        
        سبک کارت‌ها
        
        
        
        
        حس حرکت
        
        
        
        
        زیرنویس
        
        
        
        
        پاک‌سازی صدا در هر ادیت
        
        
        برای خاموش کردن: «بدون پاک‌سازی». تنظیم دقیق‌تر (اسلایدرها) در تب «صدا».
        
        
        
        
        
          
          
          
        
        
      
        
    
        
    
        
      
        فونت‌ها
        
      
        فونت‌های خودت را آپلود کن (ttf، otf یا zip). Claude نسخه‌ها را مرتب می‌کند و برای هر کدام نقش پیشنهاد می‌دهد. فونت‌های شما فقط روی همین کامپیوتر می‌مانند.

        پاک‌سازی صدا
        
        
        نویز اتاق، وزوز برق، صدای کلیک دهان و «س»های تیز حذف می‌شه؛ صدا گرم‌تر، شفاف‌تر و هم‌سطح می‌شه. تصویر دست نمی‌خوره.
        
        
        
        حالت
        
        
        
        
        
          
          
          
          
          
          
        
        
        
        
          
          
          
        
        
        
        هر اسلایدر را روی ۰ بگذاری، آن مرحله خاموش است. «بدون پاک‌سازی» یعنی صدا اصلاً دست نمی‌خورد.
        
        
        
        
        
          
        
          
        
        
        
      
        
      
        
        
        قبل / بعد
        
        
        پیش‌نمایش بگیر تا مقایسه کنی.
        
        
        
          
          
          
        
        
        
        
        فایل‌های آماده
        
        
          
      
          
    
          
  
          

  
  
          
    
          هنوز چیزی برای بازبینی نیست
          وقتی Claude برنامه و استوری‌بورد را آماده کند، این‌جا نمایش داده می‌شود.
          
    
          
      
          برنامه‌ی ادیت 
          
      
          
      
          
        
        
          
      
          
    
          
  
          

  
  
          
    
          
    
          
  
          

  
  
          
    
          
      
          
        
          چیزی یاد بده
          
        
          یادداشت، آموزش، لینک، اسکرین‌شات یا ویدیوی نمونه. Claude با «از آموزش‌ها یاد بگیر» مهارت‌ها را به‌روز می‌کند.
          
        
        
        
        
      
          
      
          صندوق آموزش
            
    
            
  
            

  
  
            
    
            
      
            دو راه برای ادیت
            
      
            
        
            حرفه‌ای — Claudeسبک — هوش مصنوعی ساده‌تر/رایگان
            
        
            چه کسیClaude Code (اپ دسکتاپ یا ترمینال)OpenCode، Kilo، Qwen Code، Gemini CLI، Cline و…
            
        
            هزینهاشتراک Claude Pro/Max، یا کلید API (پرداخت به اندازه‌ی مصرف)رایگان یا خیلی ارزان (مدل‌های رایگان؛ سقف‌ها مدام عوض می‌شوند)
            
        
            نتیجهبرنامه و استوری‌بورد کامل، پنل تصویرسازی، پنجره‌ی پاپ‌اوت، متن پشت سر، افکت‌های عمق، کنترل کیفیت با دیدن فریم‌هابرش مکث‌ها، زیرنویس برند با کلمه‌ی کلیدی، زوم، موزیک، افکت صوتی، کارت CTA
            
        
            کار هوش مصنوعیهمه‌ی تصمیم‌هافقط اصلاح املای زیرنویس (بقیه را اسکریپت‌ها انجام می‌دهند)
            
      
            
      
            هر دو: اول استوری‌بورد در بازبینی (بدون رندر)، رندر فقط بعد از تأیید تو. ویدیوها روی کامپیوتر خودت می‌مانند؛ فقط متن زیرنویس (و در حالت حرفه‌ای چند عکس کوچک) به هوش مصنوعی فرستاده می‌شود.
            

      
            حالت حرفه‌ای با Claude (پولی)
            
      
              
        
            1. Claude Code را نصب کن: اپ دسکتاپ Claude (تب Code) یا ترمینال. اشتراک Pro/Max لازم است — یا کلید API از console.anthropic.com.
              2. 
        
            2. در Claude Code، همین پوشه (mp video skillset) را باز کن. خودش CLAUDE.md و مهارت‌ها را می‌خواند.
              3. 
        
            3. این‌جا در پروژه فایل‌ها و هدف را بگذار، حالت حرفه‌ای را انتخاب کن، ذخیره را بزن و جمله را برای Claude بفرست.
              4. 
        
            4. ارزان‌تر: Claude Code را می‌شود به مدل‌های سازگارِ ارزان‌تر (Kimi، GLM، DeepSeek) وصل کرد؛ ضعیف‌تر ولی خیلی کم‌هزینه‌تر.
              5. 
      
            

      
            حالت سبک با ابزارهای رایگان
            
      
            
        
            ابزارچیستنکته
            
        
            OpenCode (پیشنهاد اول)اپ دسکتاپ + ترمینال، متن‌باز، چند مدل رایگانAGENTS.md را خودش می‌خواند
            
        
            Kiloاپ دسکتاپ (بتا)، متن‌بازشروع رایگان
            
        
            Qwen Code / Gemini CLIترمینالسقف رایگان دارند؛ QWEN.md و GEMINI.md به AGENTS.md اشاره می‌کنند
            
        
            Traeاپ دسکتاپ (ByteDance)پلن رایگان؛ برای کار خصوصی به خاطر تله‌متری توصیه نمی‌شود
            
      
            
      
              
        
            1. یکی را نصب کن و همین پوشه را در آن باز کن.
              2. 
        
            2. یک مدل خوب در فارسی انتخاب کن (مثلاً Qwen یا DeepSeek یا Gemini).
              3. 
        
            3. این‌جا حالت سبک را انتخاب کن، ذخیره را بزن و جمله را برای آن هوش مصنوعی بفرست.
              4. 
        
            4. او سه دستور اجرا می‌کند: prepare → (اصلاح زیرنویس) → storyboard. تو در بازبینی تأیید می‌کنی، بعد render --final.
              5. 
      
            
      
            اگر هوش مصنوعی گیر کرد، خودت هم می‌توانی همین دستورها را در ترمینال پوشه اجرا کنی:
            
      .venv\Scripts\python.exe .claude\skills\pro-edit\lite_edit.py prepare "نام پروژه"
            
      .venv\Scripts\python.exe .claude\skills\pro-edit\lite_edit.py storyboard "نام پروژه"
            
      .venv\Scripts\python.exe .claude\skills\pro-edit\lite_edit.py render "نام پروژه" --final
