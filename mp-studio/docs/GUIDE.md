# راهنمای استفاده — MP Studio + هوش مصنوعی

MP Studio ویدیوی خامِ صحبت تو را به ریلز تمام‌شده تبدیل می‌کند. کار سنگین (تبدیل گفتار به متن، برش،
رندر، صدا) روی کامپیوتر خودت انجام می‌شود؛ یک هوش مصنوعیِ کدنویس تصمیم‌ها را می‌گیرد. دو حالت داریم:

| | **حرفه‌ای — Claude** | **سبک — هوش مصنوعی ساده‌تر/رایگان** |
|---|---|---|
| ابزار | Claude Code (اپ دسکتاپ Claude → Code، یا ترمینال) | OpenCode، Kilo، Qwen Code، Gemini CLI، Cline، Trae… |
| هزینه | اشتراک Claude Pro/Max، یا کلید API (به اندازه‌ی مصرف) | رایگان یا خیلی ارزان؛ سقف‌های رایگان مدام عوض می‌شوند |
| نتیجه | برنامه و استوری‌بورد کامل، پنل تصویرسازی متحرک، پنجره‌ی پاپ‌اوت، متن پشت سر، افکت‌های عمق، کنترل کیفیت با دیدن فریم‌ها | برش مکث‌ها، زیرنویس برند با کلمه‌ی کلیدی، زوم روی برش‌ها، موزیک، افکت صوتی، کارت CTA با پیج |
| کار هوش مصنوعی | همه‌ی تصمیم‌ها | فقط اصلاح املای زیرنویس؛ بقیه را اسکریپت‌ها انجام می‌دهند |

**در هر دو حالت:** اول **استوری‌بورد** در MP Studio → بازبینی می‌آید (چند ثانیه، بدون رندر: متن برنامه،
جدول برش‌ها، و برای هر جمله یک عکس و صدای همان تکه). یادداشت می‌گذاری یا تأیید می‌کنی؛ رندرِ سنگین فقط بعد از تأیید.

## یک بار: نصب
1. پوشه را از GitHub بگیر (یا zip)، و `MP Studio.exe` را دوبار کلیک کن — همه‌چیز (FFmpeg، پایتون، Whisper، فونت‌ها) را خودش نصب می‌کند.
2. در **برند و استایل**: پیج، رنگ‌ها، فونت‌ها، سبک زیرنویس.

## چند فایل خام در یک پروژه
در **پروژه** → «ترتیب و نقش کلیپ‌ها» فایل‌ها را با کشیدن مرتب کن و برای هر کدام نقش بگذار:
- **اصلی**: حرف اصلی؛ به همین ترتیب پشت هم ادیت می‌شوند.
- **تکرار**: یک بار دیگر همان حرفِ کلیپ بالایی — بهترین اجرای هر جمله نگه داشته می‌شود.
- **بی‌رول**: تصویر کمکی بدون حرف (صفحه‌ی گوشی، محیط، محصول) — بی‌صدا، چند ثانیه روی برش‌ها می‌آید.

## حالت حرفه‌ای با Claude (پولی)
1. Claude Code: اپ دسکتاپ Claude (تب Code) یا `npm i -g @anthropic-ai/claude-code`. نیاز به اشتراک Pro/Max یا کلید API از console.anthropic.com.
2. در Claude Code همین پوشه را باز کن (`CLAUDE.md` و مهارت‌ها خودکار خوانده می‌شوند).
3. در MP Studio → پروژه: فایل‌ها + هدف، حالت **حرفه‌ای**، «ذخیره…»، و جمله‌ای که نشان می‌دهد را برای Claude بفرست.
4. **ارزان‌تر:** Claude Code را می‌شود به APIهای سازگار ارزان‌تر (Kimi از Moonshot، GLM از Zhipu، DeepSeek) وصل کرد — همان روال، مدل ضعیف‌تر.

## حالت سبک با ابزارهای رایگان
| ابزار | چیست | نکته |
|---|---|---|
| **OpenCode** (پیشنهاد اول) | اپ دسکتاپ + ترمینال، متن‌باز، چند مدل رایگان | `AGENTS.md` را خودش می‌خواند |
| **Kilo** | اپ دسکتاپ (بتا)، متن‌باز | شروع رایگان |
| **Qwen Code**، **Gemini CLI** | ترمینال | سقف رایگان؛ `QWEN.md` / `GEMINI.md` به AGENTS.md اشاره می‌کنند |
| **Cline / Kilo** در VS Code | افزونه‌ی ادیتور | با کلید OpenRouter و مدل‌های رایگان |
| **Trae** (ByteDance) | اپ دسکتاپ | پلن رایگان؛ به خاطر تله‌متری برای کار خصوصی توصیه نمی‌شود |

1. یکی را نصب کن و همین پوشه را در آن باز کن؛ مدلی خوب در فارسی انتخاب کن (Qwen، DeepSeek، Gemini).
2. در MP Studio → پروژه: حالت **سبک**، «ذخیره…»، جمله را برای آن هوش مصنوعی بفرست.
3. او اجرا می‌کند:
   ```
   .venv\Scripts\python.exe .claude\skills\pro-edit\lite_edit.py prepare "نام پروژه"
   (اصلاح caption_fixes.json طبق LITE_TODO.md)
   .venv\Scripts\python.exe .claude\skills\pro-edit\lite_edit.py storyboard "نام پروژه"
   ```
4. تو در **بازبینی** تأیید می‌کنی؛ بعد:
   ```
   .venv\Scripts\python.exe .claude\skills\pro-edit\lite_edit.py render "نام پروژه" --final
   ```
   خروجی + فایل زیرنویس در `mp-studio/output/<پروژه>/`.

اگر هوش مصنوعی گیر کرد، همین دستورها را خودت در ترمینالِ پوشه اجرا کن (بدون اصلاح زیرنویس هم کار می‌کند، فقط املای Whisper می‌ماند).

## حریم خصوصی
ویدیوها و صدا روی کامپیوتر خودت می‌مانند (تبدیل گفتار به متن محلی است). به هوش مصنوعی فقط متن زیرنویس‌ها
و جدول برش می‌رود؛ در حالت حرفه‌ای چند عکس کوچک هم برای کنترل کیفیت.

---
**English, short:** two modes. *Pro* = Claude Code (Pro/Max plan or API key): full plan, storyboard, motion panels,
pop-out window, depth effects, visual QC. *Lite* = any coding agent (OpenCode, Kilo, Qwen Code, Gemini CLI, Cline…),
free or cheap: `lite_edit.py prepare` → fix caption text → `storyboard` → owner approves in MP Studio → `render --final`.
Both show a storyboard (seconds, no render) before any heavy render. Agents read `AGENTS.md`.
